# Static assets

Copied to `site/assets/` by the build.

| File | What |
| --- | --- |
| `style.css` | the only stylesheet: mobile first, system fonts, dark mode via `prefers-color-scheme` |
| `app.js` | progressive enhancement without framework (< 10 KB): tag chips (include/exclude), search, grouping, swipe, sliding header, settings in `localStorage` |
| `icon.svg` | favicon |
