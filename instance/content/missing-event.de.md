# Warum ist mein Event nicht hier?

{{ site_name }} sammelt Veranstaltungen automatisch von öffentlichen Webseiten. So
kommt deine Veranstaltung am sichersten in den Kalender:

1. **Auf eine öffentliche Webseite stellen.** Die Seite liest Webseiten von
   Gemeinden, Vereinen, Veranstaltungsorten und regionalen Kalendern, aber
   **nicht** Facebook oder Instagram.
2. **Datum, Uhrzeit und Ort als Text schreiben**, nicht nur auf einem Plakat oder
   Flyer-Bild. Ein Bild kann die KI nicht zuverlässig lesen.
3. **Früh veröffentlichen**, am besten mindestens eine Woche vorher. Gesucht wird
   zweimal pro Woche, bis zu vier Wochen im Voraus.
4. **Ein öffentlicher Kalender hilft:** Trag die Veranstaltung auch in den
   Veranstaltungskalender deiner Gemeinde oder deines Landkreises ein.

Fehlt sie trotzdem? Schick die Adresse deiner Webseite an
[{{ contact_email }}](mailto:{{ contact_email }}?subject=Quelle%20vorschlagen) oder nutze
das [Feedback-Formular](../feedback/). Nach einer kurzen Prüfung kommt sie auf die
Liste der Quellen, die bei jedem Lauf abgefragt werden.
